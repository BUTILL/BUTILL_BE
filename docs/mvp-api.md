# BUTILL 분석 API 실행과 앱 연결

## 실행

프로젝트 루트에서 가상환경을 활성화한 뒤 실행한다.

```powershell
pip install -r requirements-dev.txt
$env:BUTILL_ANALYSIS_ONLY = "1"
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

브라우저에서 http://127.0.0.1:8000/docs 를 열어 요청한다.
분석 전용 모드는 DB 설정 없이 계산 API를 실행한다. 기본 모드는 기존과 같이 Supabase 설정이 필요하다.
실제 앱 기기에서 연결하려면 개발 PC 주소와 방화벽·연결 환경을 별도로 확인한다.
운영 서버는 HTTPS와 접근 제어를 구성한 뒤 사용한다.

## 현재 제공하는 기능

| 경로 | 기능 |
|---|---|
| POST /api/v1/analyses/preview | 현금흐름·Runway·위험 근거 미리보기 |
| POST /api/v1/scenarios/compare | 기본 조건과 최대 5개 시나리오 비교 |

`examples/analysis.json`, `examples/comparison.json`을 Swagger 요청 본문에 붙여 넣으면 된다.
통화는 원, 월 인덱스는 1부터 시작한다. 모든 금액은 정수만 허용한다.
분석 시작은 해당 월 첫날, 분석기간은 1~12개월이다.
월별 변경이 없으면 기본 매출·비용을 각 월에 반복 적용한다. 변경 항목의 0원도 유효한 입력이다.

## 계산 기준 초안

- 보유자금은 분석 시작 월 첫날 기준이다.
- 미지급 초기 투자비만 시작 시점에 한 번 차감한다.
- 예비자금은 지출이 아니다. 현금잔액에서 예비자금을 뺀 값을 가용잔액으로 별도 표시한다.
- 고정비 항목에는 별도 입력한 식재료비를 다시 넣지 않는다.
- 월별 `fixed_cost` 변경은 기본 고정비 합계를 대체하며 추가 합산하지 않는다.
- 지급 완료된 비정기 지출은 다시 차감하지 않는다. 미지급 지출의 예정일은 분석기간 안이어야 한다.
- 수입과 지출은 월말 기준으로 정산한다. 월중 현금 부족·세금 자동 추정은 계산하지 않는다.
- `cash_runway`와 `available_runway`는 각각 현금·가용자금 기준 결과이다.
- 잔액 0원은 `depleted`, 음수는 `shortage`이다. 기간 내 한 번이라도 부족하면 이후 회복하더라도 최초 부족을 보존한다.
- `full_months_before_shortage`는 처음 부족해지기 전의 완전한 월 수이다. 부족이 없으면 null이다.
- 초기 부족과 첫 달 말 부족은 모두 시작 월로 표시하며 `initial_balance`와 완전한 월 수를 함께 확인한다.
- 시나리오 비율은 bps 단위이다. -2000은 20% 감소, 1000은 10% 증가이다. 범위는 -10000~50000이다.
- 비율은 기본 금액과 월별 명시 변경 금액 모두에 적용한다. 고정비는 항목별로 원 단위 반올림한다.
- 시나리오의 추가 지출에는 매출·비용 변경률을 적용하지 않는다.
- `cash_shortage_month_delta`는 두 결과에 모두 부족 월이 있는 경우만 계산한다. 양수는 부족 시점 지연, 음수는 앞당김이며 비교할 수 없으면 null이다.

## 상태와 보안

preview와 compare는 요청별 계산이며 DB에 저장하지 않는다. 응답은 `persisted: false`를 포함한다.
서버 공용 메모리에 요청·시나리오를 보관하지 않으며 검증 오류에도 입력 원본을 반환하지 않는다.
이 경로는 저장형 `/stores/{id}/analyses`와 구분된 임시 미리보기 계약이다.
응답·에러 형식과 계산 기준은 프론트 연결을 위한 초안이며 TO_DECIDE의 팀 합의로 표시하거나 간주하지 않는다.
인증·저장·RLS·KAMIS 실수집·품목별 매장 비용 연결은 아직 구현하지 않았다.
금액·입력규칙의 변경은 앱 연결 전 팀에서 검토해야 한다.

## 검증

```powershell
python -m unittest discover -s tests -v
python -m pip check
```

정상 계산, 월 경계, 예비자금, 0원·음수, 지급 완료 제외, 조건별 재계산,
원본 불변성, 정수 반올림, 100개 계산 사례, 실제 앱 라우트와 검증 오류를 확인한다.
