# 소상공인 지원사업 정보 (기업마당)

> 지원사업 정보는 PRD·TRD·프로그램목록에 없는 범위다. 팀 합의 후 프로그램목록에 추가한다.
> 지원사업은 **공고 목록 조회와 링크 연결**까지만 다룬다. 신청 대행은 Charter의 Out-of-Scope이고, 현금흐름 계산에는 반영하지 않는다.
> 팀이 신청한 서울 열린데이터광장 데이터(OA-15577, OA-15572, OA-15560)는 지원사업이 아니라 **상권** 데이터다. 서울 Open API 호출 모듈(`app/database/seoul_openapi.py`)은 상권 기능에서 사용한다.

## 현재 범위

기업마당 응답을 받아 공고 모델(`SupportProgram`)로 바꾸고, 마감이 지난 공고와 중복 공고를 빼는 모듈까지 구현했다.
실제 호출 없이 테스트한다. DB 저장, 수집 실행 작업, 앱용 조회 API는 아직 없다.

| 파일 | 역할 |
|---|---|
| `app/database/bizinfo.py` | 기업마당 지원사업정보 API 호출 |
| `app/services/support_programs.py` | 공고 모델 변환, 신청기간 해석, 마감·중복 제거 |
| `app/schemas/support_programs.py` | 공고·수집 결과 모델 |

## 설정

```dotenv
BIZINFO_API_KEY=기업마당에서_발급받은_인증키
```

기업마당 API 사용 신청 양식(기관명, 신청자명, 이메일, 전화번호, 시스템명, 시스템 IP)을 내면 화면과 메일로 인증키가 나온다. 키는 서버에서만 쓴다.

## 형식

- `GET https://www.bizinfo.go.kr/uss/rss/bizinfoApi.do?crtfcKey=…&dataType=json&searchCnt=0` (0은 전체)
- 정상: `{"jsonArray": [...]}`(2026-10-27 실제 응답) 또는 `{"jsonArray": {"item": [...]}}`. 둘 다 처리한다.
- 오류: `{"reqErr": "존재하지 않는 인증키 입니다."}` → `SUPPORT_SOURCE_REJECTED` (2026-10-27 실제 호출로 확인)
- 사용 필드: `pblancId`, `pblancNm`, `jrsdInsttNm`, `bsnsSumryCn`(HTML 제거), `trgetNm`, `pldirSportRealmLclasCodeNm`, `hashTags`, `reqstBeginEndDe`, `pblancUrl`(상대 경로면 기업마당 주소를 붙인다)
- 기업마당에는 서울시·서울신용보증재단 공고도 올라온다.

## 제공 API

`GET /api/v1/support-programs` → 마감 전 서울 소상공인 지원사업 공고(마감 가까운 순). 3시간 캐시(실패 시 10분).
2026-10-27 실제 호출: 전체 1,451건 중 50건이 남았고 1.8초 걸렸다.

## 거르는 기준

기업마당의 `hashtags` 요청 조건은 실제로 결과를 거르지 않는다(`소상공인,서울`과 `소상공인`의 결과가 같았다).
그래서 전체 공고(`searchCnt=0`)를 받아 서버에서 거른다.

- 소상공인 대상: 지원대상(`trgetNm`)·제목·해시태그 중 하나에 `소상공인`
- 서울 해당: 해시태그에 `서울`, 제목이 `[서울]`, 또는 소관기관이 서울로 시작
- 제외: 제목이 `[서울]`이 아닌 다른 `[지역]`으로 시작하거나, 서울이 아닌 지방자치단체(도·광역시·특별시 등) 소관인 공고
- 전국 대상 공고(예: 소상공인 정책자금)는 서울 사장님도 해당되므로 남긴다.
- 남은 한계: 중기부 소관인 지역 사업(예: "소담스퀘어 in 경북")은 제목으로만 지역이 드러나 걸러지지 않는다.

## 정리 기준

- 신청기간은 `20220727 ~ 20220930`, `2026-10-01 ~ 2026.10.31` 형식을 읽는다. `상시`, `예산 소진 시까지`처럼 마감일이 없거나 읽을 수 없으면 `always_open=true`이고 원문은 `apply_period_text`에 남긴다.
- 마감일이 오늘(KST)보다 이전인 공고는 뺀다. 오늘 마감은 남긴다.
- 공백을 뺀 공고명이 같으면 하나만 남긴다.
- 정렬은 마감이 가까운 순, 마감일 없는 공고는 마지막이다.
- http(s)가 아닌 링크는 버린다.
